# 내부관리자 SMS 화면 — 목록 표준 적용

2026-11-05 · 선행: `2026-10-24-internal-admin-sms-design.md`, PR #1240(메인 탭 + 서브 탭)

## 왜

서브 탭으로 나눈 뒤 사용자가 보니 학교·발신번호·확인 필요 세 화면이 다른 목록 화면과 모양이 달랐다.

- 표 왼쪽 위에 제목·건수가 없다.
- 페이지 넘기기가 없다(학교·확인 필요).
- 전체 / 내 대학 칩이 없다.
- 발신번호 탭은 검색창 혼자 한 줄, 필터가 그 아래 줄이다.
- 현황 파일·새로고침·서류 기준 줄이 검색줄 자리(표 위 전체 폭)를 차지한다.
- 그 줄에 붙은 '이름 미대조 PDF N개'가 왜 거기 있는지 읽히지 않는다.
- 인스펙터가 표를 덮고, 머리 모양이 다르고, 서버를 한 번 다녀와야 열린다.

개요 탭은 `[slug]` 시절 견본(`ProjectPattern` + `makeProject` 가짜 데이터)이 남은 것이라 SMS 자료와 무관하다.

## 사용자 결정 (2026-11-05)

1. **개요 탭 삭제.** 서브 탭은 학교·발신번호·확인 필요 셋, 기본은 학교.
2. **'이름 미대조 PDF'와 '규칙 밖 파일'은 확인 필요 탭의 한 유형**으로 옮긴다. 현황 파일 줄에서는 뺀다.
3. 아래 '바꾸는 것' 전체 승인.

## 바꾸는 것

기준은 `ListPattern` 실물과 그것을 직접 구현한 화면(`handover` 인계 이력 탭, `postal/PettyCashPanel`)이다.

### 세 화면 공통

- **검색줄**: 표 위 `px-7 pt-3` 한 줄에 `ListSearch`(flex-1)와 `ListSelect`들. 학교 탭의 '확인 필요만' 체크도 이 줄.
- **표 머리**: `section p-7` 안 `header mb-4 flex justify-between`.
  - 왼쪽: 제목 · 건수(vermilion) + `ScopeChips`(전체 / 내 대학). 제목은 `학교 · N곳` / `발신번호 · N건` / `확인 필요 · N건`.
  - 오른쪽: `현황 파일 _YYMMDD · 기준 HH:mm` 문구와 `새로고침` · `서류 기준` 버튼.
- **페이지 넘기기**: `ListPagination`. 쪽 크기는 지금 발신번호 탭 값(50)을 공통으로 쓴다.
- **내 대학**: `_학교` 시트 `담당자` 열 == 로그인 운영자 `displayName`(공백 제거 후 비교).
  - 실측(현황_261017): 101곳 중 100곳이 한글 이름 하나, 1곳 `-`. 담당자는 20명.
  - 열은 **선택 열**이다 — 없으면 담당자 null, 오류 화면을 띄우지 않는다.
  - 발신번호는 그 번호의 학교(`schoolNo`)를 따라간다.
  - 확인 필요 항목은 `schoolNo` 가 있을 때만 학교를 따라간다. 학교가 없는 항목(파일 유형 포함)은 '전체'에서만 보인다.
  - '전체 (N)' 의 N 은 범위(내 대학)만 뺀 나머지 필터를 모두 적용한 건수다.
  - 기본은 '전체'(사용자 지시 2026-11-05), 내 대학은 `?mine=true`. 다른 목록과 반대라 공통 `ScopeChips` 에 `defaultMine={false}` 를 넘기고, 서버 판정(`parseMine`)도 같은 기본값을 쓴다.
- 필터·검색·칩이 바뀌면 `page` 를 지운다.

### 학교 탭

- 상단 구분 카드는 구분마다 **따로 선 카드**다(사용자 지시 2026-11-05). 4장(4년제·전문대학·대학원·초중고), 그 밖의 구분이 있을 때만 `기타` 가 5번째. 카드 안은 라벨 · `N곳` · `회선 N · 서류 미비 N · 확인 N`.
  - 처음엔 구분마다 공통 `KpiCard` 를 세웠는데, 견줄 이전 기간이 없어 늘 '비교 불가' 가 떠 있었고 회선·서류 미비·확인 줄이 카드 테두리 밖에 떠 있었다. 그다음 운영리포트 '서비스' 카드처럼 한 장에 세로선으로 칸을 나눴는데, 어느 칸이 눌렸는지 흐려졌다.
  - 면은 표면 표준(`border-line-soft bg-situation-bg p-4`). 좁으면 두 칸, 넓으면 한 줄 — 폭은 뷰포트가 아니라 컨테이너가 정한다(`@container` + `@3xl:grid-cols-4|5`). 두 칸일 때 홀로 남는 마지막 카드(기타)는 두 칸을 다 쓴다.
  - 카드 전체가 버튼이라 누르면 그 구분만 거른다(다시 누르면 해제, `page` 지움). 면(面)이라 목록 항목 표준을 쓴다 — 호버 `bg-line-soft`, 선택 `border-vermilion bg-vermilion/10` + 라벨 vermilion.
- 표의 서류 칸은 점(O·✕ 여덟 개) 대신 요약이다. 앞말은 서류 필터와 같은 원천인 제출 상태(`completeness`)를 따르고, 표시 집계(`O`·`대체` = 제출)는 뒤의 세부다 — 집계로 앞말을 정하면 '미비' 로 거른 줄이 `완비 8/8` 로 읽힌다.
  - 완비 → `완비 8/8`(표시가 어긋나면 `완비 7/8` 그대로 적는다).
  - 미비 → `7/8 · 법인인감 미제출`(미제출 이름은 둘까지, 넘으면 `외 N`, 전체는 title). ✕ 표시가 하나도 없으면 `8/8 · 미비`(vermilion).
  - 확인 안 됨, 또는 `_서류` 줄이 없으면 → `확인 안 됨`.

### 확인 필요 탭

- 유형 둘 추가: **파일 이름 미대조**(학교를 못 찾은 PDF), **규칙 밖 파일**(`_YYMMDD` 없는 xlsm).
  - 행에는 파일 이름과 사유를 적는다. 학교 칸은 비운다.
  - 계산은 지금 `parse.ts` 가 하던 것을 그대로 쓴다. 위치만 옮긴다.

### 인스펙터

- 머리는 `InspectorChrome` 과 같은 마크업(eyebrow, h3 `text-xl font-bold`, `border-b-2 border-ink`)이다. 상태 배지·PROD·수정 토글은 없다 — `InspectorChrome` 이 `ListRow` 를 요구해서 그대로 쓰지 못한다. 예전 `닫기` 버튼은 없앴다(`ListPattern` 과 같다).
- 행을 누르면 **바로** 열린다(서버 왕복 없음).
- `?school=No` 딥링크는 계속 연다. 확인 필요 탭의 대상 칸은 링크가 아니라 글자다(행을 누르면 그 자리에서 열린다).
- 열리면 본문이 `md:pr-[340px]` 로 비켜난다. 선택 행은 표준 선택 표시.
- 발신번호·확인 필요 탭의 행을 눌러도 그 학교의 인스펙터가 열린다. 학교가 없는 행은 열지 않는다.
- 섹션(제출 서류·통합 PDF·발신번호·확인 필요)은 상자 없이 자동화 실행 로그 인스펙터처럼 **ink 가로줄**(`Divider`)로 나누고 넉넉히 띄운다(`space-y-5`). 제목 오른쪽에 건수(`tabular-nums`)를 둔다 — 제출 서류 `7/8`, 발신번호·확인 필요는 개수, 통합 PDF 는 없음.
- 상태는 실행 로그 `성공` 과 같은 채운 배지(`inline-block px-2 py-0.5 text-[11px]` + `BADGE_TONE`)다. 공통 `statusBadgeTone` 은 여러 화면이 써서 건드리지 않고 이 화면에서만 묶는다.
  - 서류 줄: `제출` → done(ink) · `미제출` → attention · `대체 인정`·모르는 표시 `알 수 없음(원문)` → idle(대체·제출로 바꾸지 않는다) · 빈 칸은 배지 없이 흐린 `-`.
  - 발신번호 상태(`number-status.ts`): `일괄 등록`·`추가 등록`·`등록완료` → done · `서류 미비` → attention · 그 외 → idle.

### 기타

- 발신번호 표기 `font-mono` → 기본 폰트 + `tabular-nums`(CLAUDE.md 숫자 표기 규칙).
